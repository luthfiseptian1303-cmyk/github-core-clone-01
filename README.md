A GitHub-compatible git forge in pure TypeScript (Node 22, stdlib only, no dependencies, no network): git smart HTTP with hand-built packfiles, REST v3, GraphQL v4, and MCP over streamable HTTP — all four sharing one in-memory store, so a repository created over REST can be cloned over git, queried over GraphQL, and driven over MCP.

## Run it

```sh
node --experimental-strip-types main.ts
```
